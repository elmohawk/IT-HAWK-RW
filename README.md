# IT HAWK RW — Business Portfolio

A responsive, dark-themed portfolio website for **IT HAWK RW**, a creative and technology umbrella brand based in Rwanda.

## Included
- `index.html` — page structure and SEO/social metadata
- `styles.css` — responsive dark visual system
- `script.js` — mobile navigation, reveal effects and dynamic year
- `favicon.svg` — custom brand icon

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Before publishing
1. Replace `YOUR_EMAIL_HERE` in the email link in `index.html`.
2. Replace `YOUR_WHATSAPP_NUMBER` in the WhatsApp link with the international-format number, digits only (for example, Rwanda numbers begin with 250).
3. Add approved project images and real case studies to the work section.
4. Review all service descriptions and contact details.
5. Connect a real form backend if you want visitors to submit a form without opening their email app.

## Deployment
This is a static site and can be hosted with GitHub Pages or any static web host. For GitHub Pages, open **Settings → Pages**, select the `main` branch and `/(root)`, then save.

## Brand direction
Midnight navy, electric blue and cyan; modern typography; clean layouts; responsive-first design.
